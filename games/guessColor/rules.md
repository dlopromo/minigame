# Guess Color Rules

Guess Color is a four-slot color code game.

- Computer creates the secret code.
- Duplicate colors are allowed.
- A guess has 4 colors.
- Feedback:
  - green: correct color and position
  - orange: correct color, wrong position
  - empty: no match

Modes:

- single: one player guesses.
- coop: players share one code and take turns until solved.
- race: players race against the same code; first finish wins.
